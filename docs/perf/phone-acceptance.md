# Чек-лист ручной приёмки PWA на телефоне (Samsung Galaxy S25 Ultra) и десктопе (Firefox)

Документ представляет собой руководство и чек-лист для ручной приёмки PWA владельцем системы Canterlot в соответствии с требованиями пилота (`docs/design/pilot.md` §14, спецификация §16.2, план 1.3b Task 10).

> [!IMPORTANT]
> Ни один пункт данного чек-листа не отмечен как пройденный заранее. Все проверки выполняются владельцем вручную на целевом физическом устройстве (Samsung Galaxy S25 Ultra под управлением Chrome) и в настольном браузере Firefox.

---

## 1. Целевое окружение и конфигурация

- **Мобильное устройство**: Samsung Galaxy S25 Ultra (экран ~412×892 CSS px, One UI / Android, Chrome последней стабильной версии, клавиатуры Samsung Keyboard и Gboard).
- **Десктоп**: Настольный браузер Mozilla Firefox (Linux / macOS / Windows), стандартная вкладка.
- **Точка входа**: Единый защищённый HTTPS-ориджин за Caddy + Authelia (`forward_auth`).

---

## 2. Чек-лист приёмки на телефоне (Samsung Galaxy S25 Ultra)

### 2.1. Установка и автономный запуск (PWA Shell)
- [ ] **Установка PWA из Chrome**: При открытии веб-приложения в Chrome через меню браузера доступно действие «Установить приложение» / баннер установки PWA. Значок и название Canterlot корректно появляются на домашнем экране.
- [ ] **Запуск standalone**: При открытии с домашнего экрана приложение запускается в полноэкранном standalone-режиме (без адресной строки и панелей браузера), корректно учитывая вырезы камеры и safe-area.
- [ ] **Без сети**: в режиме полёта уже открытая вкладка остаётся на месте и показывает баннер отсутствия связи; новое открытие PWA без сети не поддерживается (service worker удалён в 1.0.0).
- [ ] **Корректный выход**: Действие «Выйти» очищает локальные данные (IndexedDB, draft mirror, кэши) и перенаправляет на URL выхода Authelia.

### 2.2. Оформление и адаптивность
- [ ] **Цветовая палитра тёмной темы**: Проверить соответствие фирменной палитре владельца (фоны `#183135`, `#1d383b`, акценты `#00f4ee`, читаемость текста `#e5f3f4`).
- [ ] **Переключение на светлую тему**: В настройках переключить тему на светлую. Все экраны сохраняют бирюзовую гамму с достаточным контрастом (WCAG AA), отсутствуют «грязные» серые заливки или нечитаемый текст.
- [ ] **Поворот экрана (Rotation)**: Повернуть устройство в альбомную ориентацию и обратно. Разметка адаптируется без наложений элементов, поля ввода и списки остаются функциональными.
- [ ] **Крупный текст 200%**: В настройках специальных возможностей Android включить масштаб текста 200%. Ни на одном экране нет горизонтальной прокрутки страницы (`scrollWidth <= clientWidth`), переносы строк корректны, кнопки не обрезаются.

### 2.3. Сенсорный ввод и экранные клавиатуры (Samsung Keyboard & Gboard)
- [ ] **Клавиша Enter (Samsung Keyboard)**: Нажатие на Enter в многострочном поле ввода добавляет новую строку и **ни при каких условиях не отправляет сообщение**. Поле снабжено `enterkeyhint="enter"`.
- [ ] **Клавиша Enter (Gboard)**: Повторить проверку на клавиатуре Google Gboard — клавиша Enter переносит строку, отправка происходит исключительно по нажатию кнопки «Отправить».
- [ ] **IME и подсказки**: Ввод текста с предиктивным набором/T9, подсказками и голосовым вводом не вызывает преждевременную отправку и не ломает курсор.
- [ ] **Вставка большого фрагмента (Paste)**: Вставить текст объёмом более 300 КиБ из буфера обмена. Текст вставляется без зависания интерфейса и без отправки.
- [ ] **Удержание экранной клавиатуры**: Нажатие кнопки «Отправить» оставляет фокус в поле ввода, экранная клавиатура не закрывается и не дергается (`interactive-widget=resizes-content`).
- [ ] **Долгое нажатие на кнопку отправки**: Долгое нажатие (long-press) открывает диалог/шторку «Отправить позже» с выбором времени, не производя немедленной отправки.

### 2.4. Вложения и бывший приём «Поделиться»
- [ ] **Приём «Поделиться» удалён в 1.0.0**: проверить, что старая установка, отправившая файл, видит на `/share` объяснение и ссылку на canterlot.
- [ ] **Пакетное вложение (три файла)**: прикрепить три разных файла кнопкой вложения в поле ввода. Все три файла добавляются в черновик.
- [ ] **Крупный файл (видео 100 МиБ)**: прикрепить видеофайл размером до 100 МиБ. Загрузка отображается прогресс-кольцом, чанк-загрузка на хаб проходит без разрыва памяти браузера.

### 2.5. Сон устройства и восстановление (AT-E-03)
- [ ] **Сон на 5 минут во время стриминга**: Запустить длинный ответ агента, выключить экран телефона блокировкой и оставить на 5 минут. Разблокировать устройство.
- [ ] **Проверка отсутствия потерь и дубликатов**: Приложение выполняет проверку синхронизации, подтягивает пропущенные события по курсору; текст ответа агента полностью совпадает с историей хаба, маркеры не двоятся и не пропадают.

### 2.6. Специальные возможности (TalkBack)
- [ ] **Навигация с помощью TalkBack**: Включить службу TalkBack. Смахнуть по элементам управления: кнопки, статусы сессий и поля ввода имеют понятные голосовые подписи на русском языке.
- [ ] **Диалоговые окна и шторки**: Открытие шторки («Инфо», настройки) удерживает фокус доступности внутри диалога; жест «Назад» закрывает шторку и корректно возвращает фокус.

### 2.7. Экспорт ответов
- [ ] **Копирование Markdown**: В шторке «Инфо» нажать «Копировать Markdown». Текст попадает в буфер обмена Android, под кнопкой появляется «Markdown скопирован».
- [ ] **Экспорт картинкой через Web Share**: В шторке «Инфо» нажать «Поделиться картинкой». Браузер генерирует PNG-карточку ответа с текстом (не пустую заливку) и открывает системное меню Android «Поделиться» для отправки в мессенджеры или сохранения в галерею. Если Web Share недоступен, кнопка называется «Копировать картинкой» и кладёт PNG в буфер обмена.

## 3. Чек-лист приёмки на десктопе (Firefox)

- [ ] **Двухпанельный режим**: На широком экране отображается список сессий слева, открытый чат по центру и панель делегирования/ленты субагентов справа.
- [ ] **Горячие клавиши отправки**: В поле ввода Enter отправляет сообщение, Shift+Enter добавляет перенос строки (проверить также переключение настройки на поведение «только кнопка»).
- [ ] **Навигация только с клавиатуры**: Пройти по интерфейсу с помощью клавиш Tab, Shift+Tab, стрелок, Enter, Space и Escape. Визуальное кольцо фокуса чётко видно на всех интерактивных элементах.
- [ ] **Экспорт в буфер обмена**: Кнопка «Копировать картинкой» кладёт PNG с текстом ответа в системный буфер обмена десктопа и показывает «Изображение скопировано в буфер обмена».

## 4. Профилирование производительности через `chrome://inspect` (P-13/P-14)

- [ ] Подключить Galaxy S25 Ultra к рабочему компьютеру через USB-кабель с включённой отладкой по ADB.
- [ ] Открыть `chrome://inspect/#devices` на компьютере и запустить сессию профилирования вкладки/PWA Canterlot.
- [ ] В длинном чате (более 100 сообщений) во время непрерывного потокового вывода агента открыть панель Performance и выполнить непрерывный ввод текста в поле сообщения в течение 1 минуты.
- [ ] **Проверка P-13**: Задержка обработки событий ввода (event-timing / input latency) p95 не превышает 100 мс.
- [ ] **Проверка P-14**: Отсутствуют длинные задачи рендеринга (Long Tasks) длительностью ≥ 500 мс в основном потоке браузера.
